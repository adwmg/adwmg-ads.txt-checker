# Privacy Policy — adWMG Checker

**Last updated:** October 29, 2026

adWMG Checker is a Chrome extension for checking publicly available `ads.txt`, `app-ads.txt`, and `sellers.json` files.

## Data use and storage

- The extension uses the active tab's domain to check advertising authorization files and show results, including automatic checks during browsing.
- The selected `sellers.json` URL, cached seller records, and cache timestamp are stored locally in the browser using Chrome's storage API.
- The extension requests public files directly from the websites being checked and the configured `sellers.json` source (by default, `https://adwmg.com/sellers.json`). These websites may receive standard network information, such as the user's IP address.
- We do not use the extension to collect browsing history, personal information, or usage analytics, and we do not sell user data or use it for advertising or tracking.

Information accessed through Chrome APIs is used only to provide the extension's stated functionality, in accordance with the Chrome Web Store User Data Policy, including its Limited Use requirements.
